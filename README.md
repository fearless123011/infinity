# Infinity

A responsive, dark-themed landing page and chat-interface preview for Infinity.

## Files
- `index.html` — page structure and content
- `styles.css` — responsive layout, colors, and visual design
- `script.js` — demo chat interactions

## Run locally
Open `index.html` in a browser, or serve this folder with any static web server.

## Important
The chat is a front-end demonstration with sample replies. It is **not connected to an AI model or backend yet**. Do not enter private or sensitive information into the demo.

## Publish with GitHub Pages
In the repository settings, open **Pages**, choose **Deploy from a branch**, select the `main` branch and `/ (root)`, then save. GitHub will provide the published website address once deployment finishes.
